# GoIT Advanced JavaScript — Homework 10

Countdown timer (flatpickr + iziToast) and snackbar (task 2).

## Run

```bash
bun install
bun run dev
```

- [http://localhost:5173](http://localhost:5173) — index
- [http://localhost:5173/1-timer.html](http://localhost:5173/1-timer.html) — timer
- [http://localhost:5173/2-snackbar.html](http://localhost:5173/2-snackbar.html) — promise generator

## Build

```bash
bun run build
```

Update `--base` in `package.json` to match your GitHub repository name before deploying to GitHub Pages.
